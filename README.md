# MovieElite Pro - WordPress Streaming Theme

## 🔥 Key Features
- **2-Row Header Architecture**: Clean top bar with prominent live AJAX search bar, logo, and accent color switcher + dedicated navigation menu bar.
- **TMDb / IMDb Bulk Importer**: 1-Click automated movie & drama fetching with full metadata, posters, ratings, cast, and video embeds.
- **Dynamic Filter Engine**: Live filtering by Type (Movies/TV Shows), Genre, Country, Release Year (auto-synced with database), Quality (4K, 1080p, 720p), and A-Z Alphabet index.
- **Homepage Block Manager**: Customizable homepage blocks with configurable content counts per block in WordPress Admin.
- **Multi-Source Embed Video Generator**: Multi-server video player tabs (AutoEmbed, VidSrc, VSEmbed, SuperEmbed) with Lights Off and Theater Mode.
- **Multi-Quality Download Manager**: Download links for 4K, 1080p, 720p, 480p with file size badges.
- **Interactive Watchlist**: Save favorites to browser localStorage with single-click heart buttons.
- **Weekly Airing Schedule Calendar**: Interactive 7-day schedule widget for airing dramas and TV shows.
- **Report Broken Player**: Built-in modal for users to report broken links directly to admin.
